    基础概念介绍¶

    • linux分类
      • Ubuntu
      • CentOS
      • Debian
    命令 作用
    pwd 查询当前路径
    ls 查询当前路径下的所有文件
    cd 切换目录
    tree 查看目录树
    clear 清屏
    命令 作用
    mkdir 新建文件夹
    rm 删除
    cp 复制
    mv 移动，重命名
    cat 查看文件内容
    exit 退出
    touch 创建空文件
    whoami 查询当前用户
    sudo -i 切换管理员账户
    exit 退出管理员账户
    ps aux 查看所有进程
    top 任务管理器
    q 退出top
    目录 作用
    /home 普通用户主目录
    /etc 系统配置文件
    /usr 普通用户程序和数据Unix System Resources
    /var 可变日志
    /bin 基础命令binaries二进制文件

    文件与目录操作¶

    命令 作用
    mkdir 创建目录
    touch 新建空白文件
    rm 删除文件
    rm -r 删除目录下所有文件
    rm -ri 删除目录下所有文件（逐个询问）
    rm -rf 删除目录下所有文件（不再询问）
    cp 复制文件
    cp -r 复制当前目录所有文件
    mv 移动/重命名文件
    命令 作用
    echo "Line 1" 显示"Line 1"
    > empty_file.txt 新建空文件
    >> 追加输出
    命令 作用
    cat 查看文件内容
    cat -n 查看文件内容（并显示行号）
    cat > filename 新建文件（按`Ctrl+D结束输入）
    less 分页查看文件
    head 查看文件开头
    head -n 20 查看前20行
    tail 查看文件末尾
    tail -f 实时跟踪文件更新（日志监控）
    tail -f app.log | grep "ERROR" 监控程序输出
    命令 作用
    grep "error" log.txt 查看文件特定行
    grep -i "error" log.txt 查看文件（忽略大小写）
    grep | less 分页查看结果
    find / -name "*.log" 查找-根目录-名字-log结尾-所有文件
    find . -name "*.log -ls 查找当前目录并返回详细信息
    find / -name "*.log -size +10M 查找特定大小文件
    命令 作用
    ps aux 查看进程
    ps -p" 显示指定PID的进程
    ps aux --sort=-%cpu" 按CPU使用率排序
    top 动态进程监控
    htop" 动态进程监控（彩色版）
    kill 结束进程
    kill -9 强制结束进程
    • systemd: 任务管理器（PID=1）
    • systemctl: 管理systemd的核心命令
      • sudo systemctl start nginx # 启动服务
      • sudo systemctl stop nginx # 停止服务
      • systemctl status # 查看系统状态
      • systemctl status sshd # 查看服务状态
    命令 作用
    ls -l 查看权限
    chmod 修改权限
    chown 修改文件所有者
    drwxr-xr-x 文件类型-所有者权限-组权限-其他权限
    chmod 755 test.txt 修改权限
    • 文件类型:
      • -: 普通文件
      • d: 目录
      • l: 链接
    • 权限位:
      • 第1位: 所有者
      • 第2位: 组
      • 第3位: 其他用户
    • 硬链接数
    • 权限类型:
      • r/4: 读
      • w/2: 写
      • x/1: 执行
      • -/0: 无权限
    • chmod权限设置
      • 权限计算: r=4, w=2, x=1
        • rwx = 4+2+1 = 7
      • chmod 755 test.txt
        • 所有者rwx，组用户r-x，其他r-x

    服务器介绍¶

    • SSH: 远程控制服务器的协议
    • SCP: 文件传输
    • ssh -L: 本地端口转发（访问本地端口，实际访问远程端口）
    • ssh -R: 远程端口转发
    • ssh -D: 动态端口转发
    命令 作用
    ssh-keygen 在本地电脑生成密钥（密钥对：私钥+公钥）
    ssh-copy-id user@服务器IP 把公钥传到服务器（安装锁）
    ssh user@服务器IP 测试
    • 私钥id_rsa-钥匙
    • 公钥id_rsa.pub-锁
    • 每台机器必须有 IP
    • 服务必须绑定IP + 端口才能被访问
    • 使用ip a命令查询ip
    • 地址如inet 172.x.x.x
    • 一台机器可以有很多端口
      • SSH → 22 端口
      • Web 服务 → 80 端口
    • 查看端口监听
      • ss -tuln
        • Netid
          • tcp与udp：不同的协议类型，面向不同的应用场景
        • State
          • LISTEN：正在等待连接
          • ESTAB：已建立连接
          • TIME-WAIT：等待关闭
          • UNCONN：udp协议常见，无连接状态
        • Local Address:Port
          • 0.0.0.0：所有网卡地址
          • 127.0.0.1：仅本机访问
      • ss -tuln | grep 8000
        • SS -tuln：输出很多行
        • |符号：把前一个命令的输出交给后一个命令
        • grep：从大量文本中筛选出包含某个关键词的行
    • 总结
      • 服务器ip + 端口确认唯一服务
    • 网页访问过程http://服务器IP:端口
      • 浏览器找到IP
      • 连接端口8000
      • 发送HTTP请求
      • 服务器返回数据
      • 浏览器渲染页面

    "Docker"¶

    容器(Docker) 把程序和运行环境打包成一个可移动的"盒子"
    镜像(Image) 只读模板，类似软件安装包
    容器(Container) 镜像运行后的实例，类似正在运行的程序
